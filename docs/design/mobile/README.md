# Mobile app design (RAKSHAK-APP Figma)

Source: https://www.figma.com/design/vxk30Mcg0kLwBbxKAlZFwt/RAKSHAK-APP (Page 1). The PNGs here are copies of the
frames taken on 2 Nov 2026 for reference. The Figma file shows the full product idea (Phases 1–4); the app
builds only Phase 1 (Implementation Plan v2.1) in this visual style.

## Frames used for Phase 1

| File | Figma frame | App screen | Differences on purpose |
| --- | --- | --- | --- |
| 01-splash | SPLASH | Welcome | "24/7 Response" replaced by "Call 112" (Phase 1 is never 24/7 monitoring); no photo yet |
| 03-create-account | 3 | Login (phone + OTP) | Phase 1 logs in with the phone number and OTP only: no email, password, Google or Apple |
| 04-location-permission | 4 | Safety setup | All permissions in one checklist, plus battery saving and a test SOS |
| 05-home | 5 | Home | No "Safety score" (not in Phase 1); status card shows guardians, live location, battery |
| 06-menu | 6 | Settings tab | Only Phase 1 items |
| 08-plan-journey | 8 | Start journey | No travel mode (plan v2); "Reach by" time added |
| 10-journey-in-progress | 10 | Journey on | No safety score; status, guardians, time left, Preview check-in, I reached safely |
| 11-are-you-safe | 11 | Check-in | Adds "Stuck in traffic"; reply time from Settings (2 min) |
| 12-journey-completed | 12 | Journey completed | No safety score or distance |
| 13-my-guardians, 21-trusted-guardians | 13, Trusted Guardian | Guardians | Status chip (invite sent / accepted / declined) |
| 17-fake-call | 17 | Fake call | — |
| 20-emergency-sos-countdown | Emergency SOS | SOS countdown | 5 seconds (Settings), "I'm Safe — cancel" and "Send SOS Now" |
| 22-live-location-sharing | Live Location Share | SOS active | Guardian status, Call 112, I'm safe |
| 41-profile, 42-settings | 41, 42 | Settings / Profile | Only Phase 1 items |
